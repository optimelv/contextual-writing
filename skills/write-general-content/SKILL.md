# Write general content

1. Read the shared [context gate](../contextual-writing/references/context-gate.md), [evidence rules](../contextual-writing/references/evidence-and-preservation.md), [language rules](../contextual-writing/references/language-and-register.md), [submission readiness](../contextual-writing/references/submission-readiness.md), and [style calibration](../contextual-writing/references/style-calibration.md) when samples exist.
2. Read [general content](references/general-content.md).
3. Resolve audience, purpose, channel, genre, language, voice, evidence, length, and desired action from existing context.
4. Ask a compact form only for missing fields that change the concept, voice, or claims.
5. Draft at the required depth. Use personality only when supported by the author and genre.
6. Run [humanizing and QA](../contextual-writing/references/humanizing-and-qa.md). Preserve a null-edit outcome for revisions. For every recipient-visible or hard-limited artifact, run the submission-readiness gate after the final edit, keep internal drafting notes outside the submitted copy, and recount with the destination's own counter when available.

Route academic deliverables to [academic content](../write-academic-content/SKILL.md), commercial conversion copy to [commercial content](../write-commercial-content/SKILL.md), and source-heavy work to [research content](../write-research-content/SKILL.md).
