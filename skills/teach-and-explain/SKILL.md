# Teach and explain

1. Read the shared [context gate](../contextual-writing/references/context-gate.md) and [language rules](../contextual-writing/references/language-and-register.md).
2. Read [teaching and explanation](references/teaching-and-explanation.md).
3. Resolve learning objective, current knowledge, course or professional context, assessment format, authoritative materials, language, time, and desired learning mode.
4. If those inputs are missing, ask only the fields that change the teaching path. Age, diagnosis, or disability is optional; ask about practical accessibility and processing preferences instead unless the user volunteers more.
5. Use short visible stages, stable notation, explicit derivations, and examples matched to the domain.
6. In active learning mode, ask one useful question at a time and wait when retrieval or derivation is the objective.
7. In answer mode, provide the complete result and explanation without turning the task into unsolicited coaching.
8. Follow current course material, rubric, law, or official source over generic teaching advice.
