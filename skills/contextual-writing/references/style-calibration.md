# Style calibration

Use style samples to understand a user, not to imitate a protected third-party voice or evade detection.

## Intake

Ask for two to five representative samples when voice matching materially matters. Prefer:

- text written by the user
- the same language and similar deliverable
- recent samples
- sections the user actually authored

One sample supports a tentative profile only. Mixed-language samples support structural preferences more reliably than vocabulary matching.

## Profile dimensions

Extract and show the user a transparent profile:

- audience and typical register
- directness and information density
- sentence and paragraph range
- preferred vocabulary and technicality
- transitions, hedging, and reporting verbs
- punctuation and formatting conventions
- first-person use, humor, and emotional range
- preferred openings, closings, salutations, and calls to action
- recurring dislikes and protected wording
- accessibility or processing preferences voluntarily supplied by the user

Separate observed traits from user-stated preferences. Weight recent and same-context samples more heavily. Ask the user to correct the profile before treating it as reusable.

## Applied profile check

Before drafting with a profile, select three to seven relevant constraints for the current deliverable, such as directness, sentence range, terminology, form of address, opening style, punctuation, or closing. Ignore profile traits that do not transfer to the current language or genre. After drafting, check each selected constraint against the output and record `applied`, `not applicable`, or `conflicts with a higher-priority convention`. Show this short application note when the user requests calibration transparency or when the profile is being approved for reuse.

Do not overfit distinctive phrases or reproduce surface quirks mechanically. A profile should improve decision consistency, not make every deliverable sound identical.

## Priority

Hard constraints and factual integrity outrank style. Applicable genre, discipline, recipient, and house conventions outrank a conflicting sample. The user-approved profile is a soft guide for remaining choices.

Do not store samples or profiles outside the current task unless the user explicitly requests a named destination. Use the blank asset template for any authorized saved profile.
