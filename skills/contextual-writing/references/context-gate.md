# Context gate

## Decision rule

Ask only when the missing answer could materially change the result. Reuse context already available. Do not force a questionnaire on a complete brief.

Material fields usually include:

- deliverable and requested action
- audience and relationship
- purpose or decision
- language, locale, and form of address
- channel, format, and hard length limit
- evidence, sources, protected facts, and template
- deadline or legal or academic effective date when relevant
- desired register, voice, and change scope

If several fields are missing, ask once in a compact form:

```md
Please fill only what is known. Write `open` where you want me to recommend a default.

Deliverable:
Audience and relationship:
Purpose or required action:
Language and locale:
Channel or file format:
Length or template constraints:
Facts and sources that must be preserved:
Tone or examples to follow:
Deadline or effective date:
```

Do not ask optional background before delivering a useful result. If the user wants a provisional draft, proceed with visible assumptions and blank fields instead of invented details.

## Sensitive context

Demographics, health, disability, neurodivergence, family status, religion, ethnicity, nationality, and age are optional. Ask only when the user requests personalization or accommodation and the answer changes the interaction or authorized content. Explain why the field matters. Allow `prefer not to say`.

Never assume that a personal trait belongs in a CV, cover letter, biography, email, or public profile merely because it was shared for collaboration preferences.

## Context sufficiency

Proceed when the available context supports the requested claim strength, recipient fit, and format. Pause when the task would otherwise require invented achievements, company facts, legal authority, citations, commitments, dates, or personal experience.
