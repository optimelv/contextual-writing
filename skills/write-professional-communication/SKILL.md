# Write professional communication

1. Read the shared [context gate](../contextual-writing/references/context-gate.md), [evidence rules](../contextual-writing/references/evidence-and-preservation.md), and [language rules](../contextual-writing/references/language-and-register.md).
2. Read [professional communication](references/professional-communication.md).
3. Resolve recipient, relationship, purpose, required action, channel, formality, evidence, deadline, and risk from available context.
4. If a material field is missing, ask the smallest relevant subset of [the intake form](assets/professional-message-intake.md).
5. Use legal or administrative mode only for disputes, rights, obligations, contracts, authorities, formal complaints, or regulated contexts. Otherwise write as a normal professional.
6. Treat operative legal, contractual, regulatory, policy, technical specification, and compliance wording as protected text. Do not humanize it into replacement language. Preserve the original and, if useful, add a separately labeled plain-language explanation that is not a substitute.
7. For completed-call follow-ups, use only grounded notes or transcripts. Separate decisions, commitments, owners, dates, blockers, and unknowns. Never reconstruct a meeting from surrounding context.
8. Draft in the requested channel and format. Do not send, post, create an external draft, or update a system without explicit authorization.
9. Make the next action visible without manufacturing deadlines, commitments, threats, or concessions.
10. For recipient-visible or hard-limit text, apply the shared [submission-readiness gate](../contextual-writing/references/submission-readiness.md). Keep internal analysis outside the message and verify one semantic action when the brief requests one.

When current law or external facts control the message, use [research content](../write-research-content/SKILL.md) before substantive drafting.

For a humanizing request involving operative wording, return this order:

1. `Original operative wording`, reproduced unchanged.
2. `Plain-language explanation`, clearly labeled non-operative and not a replacement.
3. Any material uncertainty or need for qualified review.
